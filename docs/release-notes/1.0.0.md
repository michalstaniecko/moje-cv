The first public release of CV Drawer, a free Mac app for writing a CV with a live preview of its A4 pages.

## Highlights

- **Live A4 preview** while you edit: page count, a warning when the CV runs longer than two pages, zoom.
- **Export to PDF**, an exact image of the preview, and **export to DOCX**, an editable copy for Word, Pages, LibreOffice or Google Docs with the CV's font embedded.
- **Two templates** (Classic and Modern), accent colour and font choice, a header photo with cropping and a library of consent clauses.
- **CV library** with tags, autosave, undo and JSON export and import.
- **16 interface languages**, each with its own Sample CV, plus a separate language per CV. Light and dark appearance.

## New in this version

- The `.dmg` is signed with a Developer ID and notarized by Apple, so macOS opens it without the "Open Anyway" procedure.
- CV Drawer runs in the macOS App Sandbox, so it can only reach the files you choose yourself.
- CV Drawer is also coming to the Mac App Store. Both versions share the same CV library on your Mac.

## Install

Download `CV-Drawer-1.0.0.dmg` below, open it and drag CV Drawer to Applications. Requires macOS 13 Ventura or later (Apple Silicon or Intel).

Privacy: your CVs never leave your Mac. This version only asks GitHub, at most once a day, whether a newer release exists.
